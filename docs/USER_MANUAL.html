ViroForge User Manual

Generating synthetic virome datasets with known ground truth
Version 0.20.0 Handley Lab, Washington University in St. Louis

ViroForge generates synthetic virome FASTQ datasets with complete ground truth for benchmarking virome analysis pipelines. This manual covers installation, dataset generation, and interpretation of results.

Pipeline Overview

ViroForge simulates the full virome sequencing workflow, from sample preparation through read generation. Each step models a real laboratory or computational process:

1
Collection Selection — Choose from 20 built-in virome collections (gut, skin, marine, etc.) or register your own custom genomes.
2
Contamination Injection — Add realistic non-viral contamination matching the body site: host DNA, ribosomal RNA, bacterial background, fungal background, reagent bacteria, and PhiX spike-in.
3
VLP Enrichment — Simulate virus-like particle enrichment to concentrate viruses and remove bacteria/host cells. Choose from filtration (0.1–0.45 μm pore), ultracentrifugation, or column-based kits. Skip with --no-vlp for bulk metagenome simulation.
4
Amplification Bias — Model amplification effects (linker-based PCR, MDA with phi29, or random-primed RdAB). Each method introduces characteristic GC and length biases.
5
Read Simulation — Generate paired-end Illumina reads (via InSilicoSeq) or long reads (PacBio HiFi / Nanopore via PBSIM3).
6
Artifact Injection — Add realistic sequencing artifacts: adapter read-through, PCR duplicates, low-complexity sequences, and MDA chimeras.
7
Output — FASTQ files with per-read ground truth labels (source=viral, source=host_dna, etc.), metadata JSON, and composition tables.
8
Diagnostic Report — An HTML report with plots showing dataset composition, community structure, and quality metrics.
9
Benchmarking — Score your analysis pipeline (QC, assembly, or taxonomy) against the known ground truth.

sqlite3 viroforge/data/viral_genomes.db \
  "SELECT collection_id, collection_name, n_genomes

Installation

Step 1: Clone and install

git clone https://github.com/shandley/viroforge.git
cd viroforge
pip install -e .

Step 2: Install the read simulator

pip install insilicoseq

Step 3: Build the database

viroforge setup-db

This downloads RefSeq genomes, builds the SQLite database, and populates all 20 collections. Takes a few minutes; only needed once.

Step 4: Verify

viroforge browse
## You should see 20 collections listed with genome counts.

Optional: Benchmarking support

pip install -e ".[benchmark]"

Required only for assembly benchmarking (installs mappy for minimap2 alignment).

Optional: Long-read support

Install PBSIM3 for PacBio HiFi or Nanopore read simulation:

git clone https://github.com/yukiteruono/pbsim3.git
cd pbsim3 && ./configure && make && sudo make install

Batch Generation

Generate multiple datasets from a YAML configuration:

viroforge batch config.yaml --parallel 4

Example YAML configuration:

datasets:
  - name: gut_10x
    collection_id: 1
    coverage: 10
    platform: novaseq
  - name: gut_30x
    collection_id: 1
    coverage: 30
    platform: novaseq
  - name: marine_10x
    collection_id: 5
    coverage: 10
    platform: novaseq

sweep:
  coverage: [10, 30, 50]
  amplification: [linker, mda]

When a sweep block is present, ViroForge generates every combination of the listed parameters. For example, 3 coverage values × 2 amplification methods = 6 datasets, one for each combination.

Benchmarking

ViroForge includes three benchmarking modules for scoring analysis pipelines against known ground truth.

QC Benchmark

ViroForge does not perform QC itself — it scores how well your QC tool performed. The command takes two FASTQ files as input (nothing is written):

  • --raw-reads — the original raw reads generated by ViroForge (with ground truth labels)
  • --cleaned-reads — the cleaned reads your QC tool already produced (not a file ViroForge creates)

ViroForge reads both files, checks which labeled reads survived your QC tool and which were removed, and reports a score. The workflow:

# Step 1: Generate a dataset with ground truth
viroforge generate --preset gut-standard --output data/bench

# Step 2: Run YOUR QC tool on the raw reads
fastp -i data/bench/fastq/*_R1.fastq -o cleaned_R1.fastq

# Step 3: Ask ViroForge to score what your tool did
#         (both flags are INPUTS — ViroForge reads them and prints a report)
viroforge benchmark qc \
    --raw-reads data/bench/fastq/*_R1.fastq \
    --cleaned-reads cleaned_R1.fastq
## QC Benchmark Results
## ──────────────────────────────────
## Viral retention:           97.2%  (source=viral reads kept)
## Host DNA removal:          99.1%  (source=host_dna reads removed)
## rRNA removal:              98.5%  (source=rrna reads removed)
## Bacterial removal:         94.3%  (source=bacterial_background removed)
## False positive rate:        0.8%  (viral reads incorrectly removed)
## Duplicate removal recall:  89.4%  (duplicate reads removed)

A perfect QC tool would retain 100% of source=viral reads and remove 100% of everything else.

Assembly Benchmark

Like QC benchmarking, ViroForge does not assemble anything — it scores contigs your assembler already produced. The command takes two inputs:

  • --contigs — the contig FASTA your assembler already produced (e.g., from megahit, SPAdes, or metaviralSPAdes)
  • --genomes — ViroForge's source genome FASTA (the true reference genomes the reads came from)
  • --ground-truth — ViroForge's dataset metadata JSON (optional, for expected coverage and abundance accuracy)

ViroForge aligns your contigs against the known source genomes and reports how well the assembler recovered them:

# Step 1: Assemble with YOUR assembler
megahit -1 cleaned_R1.fastq -2 cleaned_R2.fastq -o assembly/

# Step 2: Ask ViroForge to score the assembly
#         (both flags are INPUTS — ViroForge reads them and prints a report)
viroforge benchmark assembly \
    --contigs assembly/final.contigs.fa \
    --genomes data/bench/fasta/*.fasta \
    --ground-truth data/bench/metadata/*_metadata.json
## Assembly Benchmark Results
## ──────────────────────────────────
## Genomes recovered:     67 / 90   (contigs matching a known genome)
## Mean completeness:     82.3%     (fraction of each genome covered)
## Mean identity:         99.7%     (sequence accuracy of aligned regions)
## Chimeric contigs:      3 (1.2%)  (contigs spanning multiple genomes)
## N50:                   18,432 bp
## L50:                   24

Taxonomy Benchmark

Same pattern — ViroForge scores classifications your taxonomy tool already produced. The command takes:

  • --pipeline-output — the output file your classifier already produced (e.g., Kraken2 output, Centrifuge report)
  • --ground-truth — ViroForge's dataset metadata JSON (with the taxonomy block)
  • --taxdump-dir — NCBI taxonomy dump (so ViroForge can compare at genus/family level, not just exact taxids)
# Step 1: Classify with YOUR tool
kraken2 --db /path/to/db cleaned_R1.fastq > kraken_out.txt

# Step 2: Ask ViroForge to score the classifications
viroforge benchmark taxonomy \
    --pipeline-output kraken_out.txt \
    --ground-truth data/bench/metadata/*_metadata.json \
    --taxdump-dir /path/to/taxdump
## Taxonomy Benchmark Results
## ──────────────────────────────────
## Species precision:    71.2%  (correct species among all assignments)
## Species recall:       64.8%  (known species that were found)
## Family precision:     89.4%  (correct family among all assignments)
## Family recall:        83.1%  (known families that were found)
## Known viral classified: 78.3%  (reads from known genomes assigned)
## Dark matter classified: 12.1%  (unclassified genomes misassigned)

ViroForge auto-detects the format for Kraken2, Centrifuge, DIAMOND, and MMseqs2. For other tools, specify --format generic with a tab-separated file.

Interpreting the Diagnostic Report

Open generation_report.html in your browser after generating a dataset. It contains the following sections:

Composition Pie Chart

Shows the fraction of reads from each source type (viral, host DNA, rRNA, bacterial, etc.) after VLP enrichment. A well-enriched VLP virome should be >90% viral.

Before vs. After VLP

Side-by-side bar chart showing how VLP enrichment changed the composition. Before VLP: mostly bacterial. After VLP: mostly viral. This is the primary purpose of VLP enrichment.

Top Viral Families

Horizontal bar chart showing the most abundant viral families. Check if the community structure makes sense for the body site (e.g., gut should be dominated by Caudovirales phages).

Rank-Abundance Curve

Each dot represents one viral genome. The X axis is rank (1 = most abundant), the Y axis (log scale) is the read fraction from that genome.

  • Steep curve — A few viruses dominate, most are rare (typical of real viromes)
  • Flat curve — All viruses equally abundant (unusual in nature)

GC Content Distribution

Histogram of GC content across all genomes. A skewed distribution could indicate amplification bias affecting the community.

Genome Length vs. Abundance

Scatter plot checking if genome size correlates with abundance. In an unbiased dataset there should be no trend. A visible pattern could indicate VLP size bias or amplification effects.

VLP Contamination Reduction Table

Shows the removal efficiency for each contamination type. Typical values: >95% host DNA removal, >90% bacterial removal, ~40% PhiX loss (small virus, passes through filters).

Artifact Summary Table

Shows how many reads were modified by each artifact injection step (adapters, duplicates, low-complexity, chimeras).

Use Case: IBD Gut Virome Analysis

This walkthrough demonstrates a complete ViroForge workflow using Collection 10 (IBD Gut Virome) — from dataset generation through QC, assembly, and taxonomy benchmarking. The IBD virome is a good test case because it has a distinctive dysbiotic composition that differs from healthy gut.

Background

Inflammatory Bowel Disease is associated with dramatic shifts in the gut virome (Norman et al. 2015, Cell; Clooney et al. 2019, Cell Host & Microbe). Key features include:

  • Reduced crAssphage-like viruses — The dominant phage group in healthy gut is depleted ~44% in IBD
  • Expanded temperate phages — Prophage induction during inflammation leads to blooms of Drexlerviridae, Demerecviridae, and Ackermannviridae
  • Severely skewed abundance — A few viral species dominate, creating a steeper rank-abundance curve than healthy gut
  • Eukaryotic virus enrichment — Mucosal barrier damage may increase Adenoviridae and Picornaviridae

Collection 10 models these features with 90 curated genomes across 5 viral groups:

Viral GroupKey FamiliesGenomesIBD Relevance
crAssphage-like (reduced)Intestiviridae, Suoliviridae, Steigviridae, Crevaviridae2044% reduction vs. healthy
Temperate phages (increased)Drexlerviridae, Demerecviridae, Ackermannviridae35Dominant group (~39%)
MicroviridaeMicroviridae (coliphage)15Altered but maintained
InoviridaeInoviridae (filamentous)12Reduced diversity
Eukaryotic virusesAdenoviridae, Picornaviridae, Anelloviridae, Parvoviridae8Increased from mucosal damage

Step 1: Generate the Dataset

Generate an IBD gut virome dataset with VLP enrichment at 30x coverage:

viroforge generate \
    --collection-id 10 \
    --output data/ibd_virome \
    --platform novaseq \
    --coverage 30 \
    --vlp-protocol tangential_flow \
    --contamination-level realistic \
    --seed 42

VLP pore size matters. With the default 0.2 μm tangential flow, you get ~93% viral reads. Switching to --vlp-protocol tangential_flow_045 (0.45 μm pore) drops viral purity to ~85% because more bacteria pass through the larger pores. This models a real experimental trade-off: larger pores recover more large viruses but also more bacterial contamination.

For comparison, generate a bulk metagenome (no VLP enrichment) from the same collection:

viroforge generate \
    --collection-id 10 \
    --output data/ibd_bulk \
    --platform novaseq \
    --coverage 30 \
    --no-vlp \
    --seed 42
## Composition: viral 4.1% | bacterial 71.8% | host 5.0% | other 19.1%
## (No VLP enrichment — bulk metagenome composition)

The contrast illustrates what VLP enrichment does: in a bulk stool metagenome, bacteria dominate (~72%), and viruses are a small minority (~4%). VLP enrichment inverts this ratio.

Step 3: Run QC and Benchmark

Run a QC tool on the raw reads, then score its performance against ViroForge's ground truth:

    -i data/ibd_virome/fastq/*_R1.fastq \
    -I data/ibd_virome/fastq/*_R2.fastq \
    -o cleaned_R1.fastq \
    -O cleaned_R2.fastq \
    --detect_adapter_for_pe \
    --cut_right \
    --qualified_quality_phred 20
# Score QC performance against ground truth

    --raw-reads data/ibd_virome/fastq/*_R1.fastq \

Dark matter is the hard part. The 30% dark matter fraction (unclassified viral genomes with family='Unknown') is intentionally difficult to classify. A good classifier should achieve high recall on known viruses while correctly reporting dark matter reads as unclassified rather than misassigning them. The stratified report lets you evaluate both cases separately.

Compare across tools by generating a single dataset and running multiple classifiers:

# Same dataset, different classifiers
viroforge benchmark taxonomy --pipeline-output kraken_out.txt    --ground-truth metadata.json --taxdump-dir taxdump/
viroforge benchmark taxonomy --pipeline-output centrifuge_out.tsv --ground-truth metadata.json --taxdump-dir taxdump/
viroforge benchmark taxonomy --pipeline-output diamond_out.tsv   --ground-truth metadata.json --taxdump-dir taxdump/ --format diamond

# Compare the reports
viroforge compare \
    kraken_benchmark.json \
    centrifuge_benchmark.json \
    diamond_benchmark.json

This is the core ViroForge workflow: generate a dataset with known ground truth, run your analysis tools, and get objective performance metrics. The IBD collection is particularly useful for benchmarking because its dysbiotic composition challenges tools differently than a healthy gut virome — the skewed abundance distribution and temperate phage blooms test how well tools handle uneven coverage.

Full benchmarking pipeline

# 1. Generate dataset with ground truth
viroforge generate --preset gut-standard --output data/bench

# 2. Run your QC tool
fastp -i data/bench/fastq/*_R1.fastq \
      -I data/bench/fastq/*_R2.fastq \
      -o cleaned_R1.fastq -O cleaned_R2.fastq

# 3. Score QC performance
viroforge benchmark qc \
    --raw-reads data/bench/fastq/*_R1.fastq \
    --cleaned-reads cleaned_R1.fastq

# 4. Assemble
megahit -1 cleaned_R1.fastq -2 cleaned_R2.fastq -o assembly/

# 5. Score assembly
viroforge benchmark assembly \
    --contigs assembly/final.contigs.fa \
    --genomes data/bench/fasta/*.fasta \
    --ground-truth data/bench/metadata/*_metadata.json

# 6. Classify
kraken2 --db /path/to/db cleaned_R1.fastq > kraken_out.txt

# 7. Score taxonomy
viroforge benchmark taxonomy \
    --pipeline-output kraken_out.txt \
    --ground-truth data/bench/metadata/*_metadata.json \
    --taxdump-dir /path/to/taxdump
