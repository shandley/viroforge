Database Setup Required

ViroForge needs a local genome database before you can browse collections or generate datasets. This is a one-time setup that downloads viral genomes from NCBI RefSeq and builds a SQLite database (~500 MB).

Run this command in your terminal:
viroforge setup-db

This will take several minutes on first run (RefSeq download + database build). Once complete, refresh this page and all features will be available.

Troubleshooting
  • Network failed partway? Try viroforge setup-db --skip-download to retry with already-downloaded data.
  • ICTV website down? Try viroforge setup-db --skip-taxonomy to build without taxonomy (can add later).
  • Corrupted download? Try viroforge setup-db --force to re-download everything.
