QC Benchmark

File path to the original ViroForge R1 reads (contains source= ground truth labels in headers)

Advanced: Keep/Remove policy overrides
By default, viral and erv_endogenous reads are scored as "should keep"; host_dna, rrna, phix, reagent, and erv_exogenous as "should remove". Override any source type here (e.g. erv_endogenous:remove if your QC tool strips endogenous retroviruses). Most users can leave this blank.
